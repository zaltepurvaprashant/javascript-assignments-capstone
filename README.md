# JavaScript Curriculum: Assignments & Capstone Project

This repository contains all the practical programming exercises and the final capstone project for the JavaScript curriculum.

## Repository Structure

* **`assignment1.js`** - Variables, Data Types, and Console Operations
* **`assignment2.js`** - Operators, Expressions, and Input Handling
* **`assignment3.js`** - Conditional Logic Implementation
* **`assignment4.js`** - Loop Control Structures
* **`assignment5.js`** - Function Architecture and Scope
* **`assignment6.js`** - Arrays, Objects, and Core Methods
* **`capstone-project.js`** - Interactive Product Inventory & Analytics Dashboard

## How to Run the Code

1. Ensure you have Node.js installed on your computer.
2. Open your terminal in the project directory.
3. Run any individual script using Node.js:
   ```bash
   node assignment1.js
   node capstone-project.js
